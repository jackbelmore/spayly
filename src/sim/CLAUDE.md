# src/sim — frozen reference for the Godot port

The web build moved to the `web-version` branch; what is left of `src/` on `main` is read by `godot/tools/` only.

- Never edit it to change the game: port the change into `godot/Spayly.Sim/`. *(unenforced)*
- `catalog.ts` and `satellites.ts` feed `godot/tools/prepare-textures.mjs` and `gen-satellites.mjs` (→ `Satellites.g.cs`);
  `src/render/{gapFill,noise,mapDecode}.ts` are the texture bake. Delete none of them. *(`npm run typecheck`, `node godot/tools/start.mjs --prepare-only`)*
- `satellites.ts` is generated by `scripts/fetch-ephemeris.mjs` (`npm run ephemeris`): edit the generator, never the output.
- Its vitest suite and the layer law live on `web-version`; physics is proven by `dotnet test godot/Spayly.Sim.Tests`.
