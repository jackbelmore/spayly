# src/sim — physics

Pure simulation. This is the one layer with real test coverage; keep it that way.

## Imports
- Nothing outside `src/sim/`. No `three`, no DOM, no `window`/`document`/`performance`, no `import.meta`.
  It must run under plain Node in vitest. *(`tests/layering.test.ts`)*
- Needs render-side knowledge? Take a callback, as `resolveCollision` does. Never import upward.

## Units
- **km, kg, seconds, radians** everywhere — `Body.radius` is km, `Universe.time` is seconds since `epochJD`.
- **Except `impact.ts`, which is SI (m, kg, s, J) end to end**, because the Collins/Melosh/Marcus formulas
  are. The conversion happens at the boundary in `collide.ts`, and `ImpactReport` distances are metres.
  This is the easiest mistake to make in the repo.
- Degrees appear only in IAU `Rotation` fields. Frame is ecliptic J2000, +z ecliptic north.

## Integrator
- Leapfrog must stay symplectic and exactly time-reversible — `tests/universe.test.ts` asserts energy
  conservation and reversibility and will catch you.
- No velocity- or time-dependent forces. No clamping or renormalising of state inside `step()`.
- Time warp is throttled by the substep budget, never by skipping physics.

## Body state
- `mass0`/`radius0` are catalogue values: written once in `makeBody`, never again.
- `damage.*` is written only here. Render caches `damage.version`, so **bump `version` whenever `craters`
  changes** or the repaint silently never happens. *(unenforced — nothing catches this)*
- Body `id`s are stable and unique; views key off them.

## satellites.ts is generated
`satellites.ts` (23 moons + dwarf planets) is generated by `scripts/fetch-ephemeris.mjs` — edit the
generator, never the output file. `npm run ephemeris` regenerates it from JPL.

## Verify
`npm test`. Every physics change needs a test, and a conservation or reversibility test is worth more than
a golden-value one. The 60 s `testTimeout` in `vite.config.ts` is deliberate — a year of the full system is
hundreds of thousands of substeps. Never weaken an assertion to make a change pass.
